# RISCV_CPU
SystemVerilog implementation of a single-cycle RISC-V CPU with verification, simulation and FPGA deployment support.

## Features

- SystemVerilog RTL design
- Verilator simulation
- GTKWave debugging
- Verification testbenches
- Optional FPGA deployment

## Project Structure

rtl/      - RTL modules
tb/       - Testbenches
docs/     - Documentation
results/  - Simulation results and screenshots
